# AGENTS.md


## Project overview
nu-waves is a Python package which core allows to propagate flavor oscillation
effects on neutrinos.


## Repository structure
- `src/nu_waves`: python package source code
- `tests/`: tests that ensure the code is producing accurate results.


## Coding policy

### Spelling

General spelling uses `PascalCase` for classes/structs/namespaces
and also file names, 
while all the rest is using `camelCase` (functions, methods, members...).
